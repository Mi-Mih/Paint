# 🎨 Paint

Код был написан руками в далёком 2020 году...

Небольшой браузерный графический редактор на чистых HTML, CSS и JavaScript. Позволяет рисовать кистью и геометрическими фигурами, выбирать цвет и толщину линий, использовать ластик, пипетку и заливку, а также сохранять готовое изображение.

## ✨ Возможности

- 🖌️ свободное рисование кистью;
- 📏 настройка толщины линии;
- 🔵 окружности и эллипсы;
- ⬜ квадраты и прямоугольники;
- 📐 ломаные линии;
- 🎨 выбор цвета и пипетка;
- 🪣 заливка области;
- 🧽 ластик и очистка холста;
- 💾 сохранение рисунка в PNG.

## 🚀 Запуск

Проект не требует установки зависимостей. Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

После этого перейдите по адресу `http://localhost:8000`.
